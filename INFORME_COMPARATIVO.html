3. Sistema de Estilos

frontend — PROBLEMAS GRAVES
  • 59KB+ estilos.scss monolítico
  • 4 sistemas simultáneos: Bootstrap SCSS + Styled-components + MUI emotion + CSS plano
  • Duplicación: NavBar.scss + NavBar.css
  • CSS sin namespacing → colisiones
  • Colores hardcodeados en múltiples lugares
  • Dependencias: bootstrap, react-bootstrap, @mui/material, @emotion/*, styled-components
  • Fuente Google Fonts (request externo)
360-v2 — MEJORA SUSTANCIAL
  • Tailwind CSS v4 utility-first: purga automática de CSS no usado
  • shadcn/ui: Componentes headless Radix UI estilizados con Tailwind
  • Variables CSS nativas con OKLCH + dark mode via next-themes
  • Un solo index.css de ~150 líneas con variables de diseño
  • @fontsource/inter: Fuente auto-hosteada (sin request externo)
  • Utilidad cn() con tailwind-merge + clsx
  • Cero dependencias CSS externas

11. Hallazgos de Código y Buenas Prácticas

Problemas en frontend
  • Archivos monstruo: 3203 líneas (ProspectosDashboard), 2413 (ProspectoDetalle) — violación SRP
  • CSS monolítico: estilos.scss de ~59KB sin modularizar
  • Duplicación de lógica: Estados de prospecto definidos en múltiples lugares
  • Config en components/: config.js mal ubicado
  • Sin lazy loading: Toda la app en un bundle
  • Sin TypeScript: Errores prevenibles en producción
  • 4 sistemas de estilos: Bootstrap + MUI + Emotion + Styled-components
  • AccessDenied duplicado: AccessDenied.jsx + UnknownRole.jsx suelto
Aciertos en 360-v2
  • Arquitectura feature-first: Cada feature con pages/ y components/
  • Componentes atómicos: 36 shadcn componentes reutilizables en ui/
  • Rutas centralizadas: app/routes.tsx con lazy loading + alias legacy
  • Capa lib/ separada: API client, auth, config, utils
  • Validación Zod: Schemas de formularios tipados
  • Sistema de temas: next-themes con dark mode completo
  • TanStack Table: Data grid headless, performante y extensible
  • Sonner: Reemplaza SweetAlert2 (más liviano, moderno)
  • Prettier + plugin Tailwind: Formateo automático de clases
  • Code splitting: manualChunks optimizados (react-vendor, recharts-vendor, ui-vendor)
